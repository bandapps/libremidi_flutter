# Classification of every file under src/libremidi/.
#
# This directory sits ahead of third_party on the include path, so each file
# here either shadows a vendored libremidi header or is one of ours. Which of
# the two it is has to be written down, because both get silently dangerous:
#
#   * A patched copy whose vendored original changes is a stale file shadowing
#     a newer one — it reverts whatever upstream fixed, and still compiles.
#   * A file of ours becomes a shadow the moment upstream adds that same path.
#
# Format, one line per file:
#
#   <fingerprint>  <path relative to src/libremidi/>   patched copy
#   -              <path relative to src/libremidi/>   ours, no upstream
#
# The fingerprint is FNV-1a over the *vendored original*, line endings
# normalised. test/patched_headers_test.dart checks it and prints the current
# value when it differs.
#
# When it fails after a libremidi update: re-apply the local fix on top of the
# new upstream file, confirm the patch notes at the top of the copy still
# describe reality, verify, and only then record the new fingerprint. Updating
# the number alone throws away the fix.
